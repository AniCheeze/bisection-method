1. Назначение программы
Консольная программа на языке Java для приближённого решения нелинейного уравнения методом бисекции (методом деления отрезка пополам).

Решаемое уравнение:
f(x) = x³ − x − 2 = 0
Отрезок поиска корня: [1; 2]
Требуемая точность: ε = 0,0001

2. Теоретические сведения
2.1. Метод бисекции
Метод бисекции — численный метод решения нелинейных уравнений, основанный на теореме Больцано — Коши:

Если функция f(x) непрерывна на отрезке [a; b] и принимает на его концах значения разных знаков (f(a) · f(b) < 0), то внутри отрезка существует хотя бы один корень уравнения f(x) = 0.

2.2. Алгоритм
Задать границы отрезка a и b, точность ε.

Проверить условие f(a) · f(b) < 0. Если не выполнено — корень не гарантирован.

Найти середину отрезка: mid = (a + b) / 2.

Вычислить f(mid).

Определить, в какой половине находится корень:

если f(a) · f(mid) < 0, то b = mid;

иначе a = mid.

Повторять шаги 3–5, пока длина отрезка не станет меньше 2ε.

Приближённое значение корня: x ≈ (a + b) / 2.

2.3. Условие остановки
Итерации продолжаются, пока выполняется:

(b − a) / 2 > ε
Как только половина длины текущего отрезка становится меньше или равна ε, вычисления прекращаются.

2.4. Оценка количества итераций
Количество итераций для достижения точности ε на отрезке длиной (b − a):

n ≥ log₂((b − a) / ε)
Для наших данных: n ≥ log₂(1 / 0,0001) ≈ 13,3, то есть 14 итераций.

2.5. Скорость сходимости
Метод бисекции имеет линейную скорость сходимости: на каждой итерации погрешность уменьшается примерно в 2 раза.

3. Структура программы
Элемент	Назначение
f(double x)	Вычисляет значение функции x³ − x − 2
bisection(double a, double b, double eps)	Реализует метод бисекции
main(String[] args)	Точка входа, разбор аргументов, вывод результата

5. Описание методов
4.1. Метод f
java
public static double f(double x)
Назначение: вычисление значения функции f(x) = x³ − x − 2.

Параметры:

x — аргумент функции.

Возвращает: значение f(x).

4.2. Метод bisection
public static double bisection(double x, double y, double acc)
Назначение: находит приближённый корень уравнения на отрезке [a; b] с точностью ε.

Параметры:
x — левая граница отрезка;
y — правая граница отрезка;
acc — требуемая точность.

Возвращает: приближённое значение корня.

4.3. Метод main
public static void main(String[] args)
Назначение: точка входа. Задаёт параметры по умолчанию (a = 1, b = 2, eps = 0.0001), при необходимости считывает их из аргументов командной строки, вызывает метод бисекции и выводит результат.

5. Запуск программы
5.1. Компиляция
javac BisectionMethod.java

6. Пример работы программы
Ввод
java BisectionMethod 1 2 0.0001
Вывод
Уравнение: x^3 - x - 2 = 0
Приближённый корень: x = 1.521423

8. Ограничения метода
Требуется, чтобы функция была непрерывна на отрезке.

Требуется, чтобы на концах отрезка функция принимала значения разных знаков.

Если на отрезке несколько корней — метод найдёт только один из них.

Скорость сходимости линейная — метод уступает методу Ньютона и методу секущих, но выигрывает в надёжности.

9. Возможные улучшения

Вывод промежуточных итераций в табличном виде.

Сохранение результатов в файл.

Графическая визуализация процесса сходимости.
